From a new Mac Studio to your own AI agent

A step-by-step checklist, in order. Tap the circle next to each step when it's done; this page remembers your progress on this device. Steps marked Brad does this with you are the technical ones we'll do together.

The plan: by the end, your Mac Studio runs your own private AI assistant 24/7. You message it from your phone like a person, it remembers what matters, and the private version runs entirely on your own hardware.

What you'll need

  • Your Mac Studio, plugged in, with internet
  • Your Apple Account (Apple ID) and password
  • Your iPhone
  • An external drive for backups (1 TB or larger)
  • About 2 hours, split over two sessions
  • Ideally a battery backup (UPS) for the Mac
Phase 1 · about 30 minutes · you can do this alone

Set up the Mac

Get the Mac safe, updated and ready to stay on around the clock.

Turn it on and run the Setup Assistant

Follow the on-screen steps. Sign in with your Apple Account when asked, and create your Mac user account with a strong password you'll remember.

Done when you see the desktop.

Turn on FileVault (disk encryption)

Go to Apple menu › System Settings › Privacy & Security › FileVault and turn it on.

When it asks how to unlock, choose Create a recovery key and do not use my iCloud account. Write the key down and store it somewhere safe, away from the Mac.

Good to know: with FileVault on, after a power outage the Mac waits for your password before the assistant restarts. A battery backup (UPS) prevents most of those restarts. We recommend keeping FileVault on, because your assistant will hold private information.

Source: Apple · Protect data with FileVault

Install every update

Go to System Settings › General › Software Update and install anything waiting. Then tap the ⓘ next to Automatic Updates and turn on all three:

  • Download new updates when available
  • Install macOS updates
  • Install Security Responses and system files

Source: Apple · Keep your Mac up to date

Keep it awake, and have it restart after a power cut

Go to System Settings › Energy and turn on:

  • Prevent automatic sleeping when the display is off
  • Wake for network access
  • Start up when power is connected: set to Always (if you see this option)

Sources: Apple · Energy settings · Apple · Start up when power is connected

Set up Time Machine backups

Plug in the external drive. Click the Time Machine icon in the menu bar, then Open Time Machine Settings › Add Backup Disk, and pick the drive. Turn on encryption for the backup when offered.

No icon? Go to System Settings › Control Center › Time Machine › Show in Menu Bar.

Source: Apple · Back up with Time Machine

Check how much memory your Mac has

Go to Apple menu › About This Mac and note the Memory number (for example 64 GB or 128 GB). Text it to Brad. It decides which private AI model your Mac can run.

Phase 2 · about 20 minutes · Brad does this with you

Install the private AI engine

This is the part that keeps patient information on your Mac. It runs AI models directly on your Mac Studio, with nothing sent to an outside company.

Install Ollama (runs AI models on your Mac)

  1. Download Ollama for macOS from ollama.com/download.
  2. Open the download and drag Ollama into Applications.
  3. Open it once and allow it to install its command-line tool when asked.

Source: Ollama · macOS

Download a private model

Open Terminal (press ⌘ Space, type Terminal, press Return) and paste the command for your Mac's memory. Downloads are large, so let it finish.

Your memoryStarting modelDownload
36–64 GBGemma 4 (26B)~16–19 GB
96–128 GB+gpt-oss (120B)~65 GB
ollama pull gemma4:26b
ollama pull gpt-oss:120b

Type the name exactly as shown. Plain gemma4 downloads a much smaller model. Done when Terminal shows success. Brad will confirm the best model for your exact Mac; bigger models are smarter but need more memory.

Sources: ollama.com/library/gemma4 · ollama.com/library/gpt-oss · OpenClaw · local models

Phase 3 · about 30 minutes · Brad does this with you

Install your agent

Your agent runs on OpenClaw, the same open-source foundation Lucius is built on. It runs in the background all the time and connects your AI to your phone.

Install OpenClaw

Paste this into Terminal. It installs everything it needs, then starts the setup wizard.

curl -fsSL https://openclaw.ai/install.sh | bash

Source: OpenClaw · Install

Run the setup wizard and choose the private model

The installer opens the setup wizard by itself. If it didn't, start it with the command below. Choose Custom setup, then for the model choose Ollama › Local only.

openclaw onboard

When it asks for the Ollama address, enter exactly:

http://127.0.0.1:11434

Not the /v1 address. An address ending in /v1 breaks your agent's tools.

When the wizard finishes, your agent is running inside the Terminal window and would stop if you closed it. To keep it running all the time, press Control-C in Terminal, then run:

openclaw gateway install

This sets your agent to start by itself and keep running in the background.

Check it's running: close Terminal, open a new Terminal window and run openclaw gateway status. It should show it's running on port 18789.

openclaw gateway status

Optional menu-bar app. The OpenClaw Mac app (needs macOS 26.2 or later) shows your agent's status and lets you chat with it. Install it after this step and it connects to the agent you just set up. If you ever set up through the app instead of Terminal, turn on Keep OpenClaw running when the app is closed and Launch at login; both start off.

Sources: OpenClaw · Getting started · OpenClaw · Ollama · OpenClaw · macOS app · Mac app background service

Optional: add a smarter cloud model for non-patient work

For marketing, writing and research (never patient information), your agent can also use ChatGPT or Claude. If you have a ChatGPT subscription, sign in with:

openclaw models auth login --provider openai

Rule: anything about patients stays on the private local model. Cloud models are only for public-facing work like posts, blogs and emails.

Source: OpenClaw · OpenAI

Phase 4 · about 15 minutes

Talk to it from your phone

We'll start with Telegram, the simplest and most reliable option. You'll message your agent like a contact.

Create your agent's Telegram account

  1. Install Telegram on your iPhone and sign up.
  2. Search for @BotFather (blue check mark) and open it.
  3. Send /newbot, then choose your agent's name and a username ending in "bot".
  4. BotFather replies with a token (a long code). Send it to Brad privately; don't post it anywhere.

Source: OpenClaw · Telegram setup

Connect Telegram to your agent · Brad does this with you

openclaw channels add --channel telegram --token <your-bot-token>
openclaw channels status --probe

Now message your bot "hello" from your iPhone. It replies with a pairing code. Approve yourself so only you can talk to it:

openclaw pairing approve telegram <CODE>

Done when your agent answers you on your phone.

Source: OpenClaw · Telegram setup · Pairing

Reach your Mac securely from anywhere

Install Tailscale on the Mac (tailscale.com/download/mac) and on your iPhone (App Store), and sign in to the same account on both. This creates a private, encrypted link between your devices only.

Then Brad turns on private dashboard access and restarts the agent so it takes effect:

openclaw config set gateway.tailscale.mode serve
openclaw gateway restart

Never use "Funnel". It would make your agent public on the internet.

Sources: Tailscale · Mac · Tailscale · iPhone · OpenClaw · Tailscale

Phase 5 · the fun part · about 30 minutes together

Give it a name and a personality

Your agent reads a few short files every time it starts. These make it yours. They live in your agent's workspace folder on the Mac.

IDENTITY: its name

Pick a name and a one-line description. Lucius is Brad's; yours can be anything you like.

Example: "Name: Sterling. A calm, precise assistant for Lefkowitz Plastic Surgery."

SOUL: how it talks and what it won't do

Its tone and its boundaries. For example: warm and concise; never gives medical advice to patients; always asks before sending anything outside the practice.

USER: about you

How you like to work: your schedule, how you like updates (short or detailed), the practice's priorities, who's on your team.

AGENTS: its job description

What it does day to day: draft posts and emails for approval, summarize your day, prepare consult briefs, keep notes. Its memory builds over time from your conversations.

Source: OpenClaw · Agent workspace · Memory

Phase 6 · about 20 minutes · Brad does this with you

Lock it down

Before any practice information goes in, we tighten the settings.

Keep its memory search on the Mac

By default, the memory search feature uses an outside service. Brad switches it to a local option so your notes never leave the Mac.

Source: OpenClaw · Memory

Apply the security baseline and run the audit

Brad applies OpenClaw's hardened security settings (limits what the agent can touch on the Mac), then runs the built-in check:

openclaw security audit --deep

Done when the audit comes back clean.

Sources: OpenClaw · Security · Hardened baseline

Agree the patient-data rules

  • No patient information until your compliance review is done.
  • Patient work only on the private local model, never a cloud model.
  • Only you (and anyone you approve) can message the agent.
  • Add-on "skills" from the internet only after Brad reviews them.
Phase 7 · ongoing

Go live and keep it healthy

Your first week with it

Talk to it every day. Try: "Draft three Instagram captions about deep plane facelift recovery." "Summarize this article for me." "Remind me what we discussed on Monday." The more you use it, the more it learns how you work.

Monthly: update it

After a Time Machine backup, run:

openclaw update
openclaw doctor --fix

Source: OpenClaw · Updating
